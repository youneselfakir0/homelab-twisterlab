TwisterLab

Un homelab distribué où le cerveau (Hermes) orchestre des bras spécialisés (OpenClaw & OpenCode) sur trois nœuds hétérogènes. Zéro confiance, vérification systématique, automatisation totale.

Voir le dépôt Explorer l'architecture

Le Triptyque d'Agents

Une spécialisation stricte pour une efficacité maximale.

Hermes

L'Orchestrateur (Le Cerveau)

Coordonne la flotte via A2A. Il gère le Kanban, distribue les tâches, agrège les preuves et valide les artefacts.

  • Routing A2A peer-to-peer
  • Gestion du cycle de vie Kanban
  • Vérification SHA-256

OpenClaw

Le Runtime (Les Bras)

L'interface avec le monde réel. Exécute des plugins, des skills et interagit avec 500+ apps via Composio.

  • Intégration Composio CLI
  • Exécution de Skills spécialisés
  • Interaction API / Webhooks

OpenCode

Le Codeur (L'Expert)

L'agent dédié au développement. Écrit du code propre, réalise des reviews et gère les Pull Requests.

  • Génération de scripts Python/JS
  • Analyse de codebase locale
  • Automatisation GitHub API
