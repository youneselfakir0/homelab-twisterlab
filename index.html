L'orchestration sans preuve, c'est de la narration.

L'illusion du "OK"

Un exécuteur qui dit « OK » n'est pas une preuve. Nous exigeons l'artefact et son hash.

Le piège du routeur auto

L'automatisation aveugle cache qui a fait quoi. Nous utilisons un routage explicite.

La doc divergente

Une doc qui ne reflète pas le réel est un mensonge. Notre source de vérité est mesurée.

Hermes orchestre. OpenClaw contrôle. OpenCode exécute.

Hermes — Le moteur

Orchestration déterministe. Pas de routeur automatique : l'orchestrateur route lui-même, vers le worker juste nécessaire.

• Routing A2A peer-to-peer
• Gestion du cycle de vie Kanban

OpenClaw — Le contrôle

Control plane. Planifie, valide, rapporte. Le KANBAN est registre, pas routeur.

• Intégration Composio CLI
• Execution de Skills spécialisés

OpenCode — L'exécution

Boucle d'inférence free-tier bridgée vers Hermes. Aucun modèle local : la GTX 1050 ne sert pas de modèle.

• Génération de scripts Python/JS
• Automatisation GitHub API
